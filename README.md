# ResumeIQ

AI-powered resume analyzer built using Flask and Gemini AI.

## Features

- ATS score analysis
- AI-generated resume insights
- Missing skills detection
- Resume improvement suggestions
- Recommended project ideas
- Resume comparison support
- Professional PDF report export
- Dynamic frontend rendering
- Structured JSON AI responses
- Fallback handling for invalid AI output

---

## Tech Stack

- Python
- Flask
- HTML/CSS/JavaScript
- Gemini AI API
- ReportLab
- Git & GitHub

## Installation

```bash
git clone https://github.com/vinayprincemb-cmd/ResumeIQ-project.git
cd ResumeIQ-project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create `.env` file:

```env
GEMINI_API_KEY=your_api_key
```

Run application:

```bash
python app.py
```
